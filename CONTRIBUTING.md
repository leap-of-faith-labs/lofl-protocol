# Contributing

1. Changes are proposed as a new version that supersedes the old one — never as an edit to a published version.
2. Every proposal carries its own dissent paragraph: the strongest reason not to make the change.
3. The first external contributor whose change is merged is the charter's trigger event (CHARTER.md §5). The README will say so on the day it happens.

Discussion happens in Discussions, not only Issues — disagreement needs a place that is not a bug tracker.
